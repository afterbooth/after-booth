# AGENT_MISTAKES

실제로 재현·확인된 에이전트 실수만 적는다. 추측성 예방 규칙은 적지 않는다. 구현 전에 이 파일을 읽는다.

## 같은 PC의 finplay에서 확인된 것 (2026-07~08)

1. **같은 폴더에서 브랜치를 바꾸지 않는다.** 다른 세션이 편집 중인 파일이 사라졌다. 다른 브랜치는 worktree에서만 작업한다.
2. **Gradle을 돌리기 전에 다른 빌드가 도는지 본다.** 같은 폴더 빌드가 겹치면 서로 깨진다. `:test FAILED`인데 실패한 테스트가 0건이면 빌드 충돌이다. 그냥 재실행하지 말고 `gradlew --stop` → java 프로세스가 사라진 것 확인 → 단독 재실행.
3. **Testcontainers는 PowerShell 도구로 돌린다.** Git Bash 도구에서는 Docker 소켓을 못 찾아 전량 실패했다.
4. **전체 테스트 스위트를 습관적으로 돌리지 않는다.** 메모리 부족으로 죽은 적이 있다. 평소에는 compile + spotlessCheck + 영향받는 테스트만 `--tests`로.
