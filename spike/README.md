# spike

Phase 0 기술 스파이크. **버려도 되는 코드**만 둔다. 결론은 `REPORT.md`에 정리하고, 제품 코드는 여기서 import하지 않는다.

- 키는 `node --env-file=../.env <스크립트>`처럼 런타임이 직접 읽게 한다 (hook이 사람에게 묻는다)
- `samples/`: 측정용 사진·음성. 사람 얼굴·개인정보 금지
- `out/`: 원본 응답·측정 로그 (커밋 안 함). replay에 쓸 응답은 `fixtures/`로 옮긴다

REPORT.md에 들어갈 것: 기능별 가능/불가, 실제 모델 ID·엔드포인트, 지연(p50/최대), 정확도, 호출당 비용, 실패 시 대안.
